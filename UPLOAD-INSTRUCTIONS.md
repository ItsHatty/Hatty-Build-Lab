# Hatty Build Lab tether integration fix

**Upload all extracted files and the data folder to the repository root**, replacing existing files. In particular, verify GitHub `build-generator.js` and `hatty-live.js` both show the new commit. The website results must display **Engine: tether-integration-2**. If this label is missing, the site is still running old code. If the label appears but 80 Speed With Ball / 66 Speed appears on the tested body, the site will show a safety error instead of returning the invalid build.

This narrow rule applies ONLY to SG 6ft5 233 lb 6ft10 wingspan, Speed With Ball >= 80. It does not establish universal game tethers. The builder remains experimental and does not optimize cap breakers.
